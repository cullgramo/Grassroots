# Grassroots

Find Gaelic games near you: hurling, Gaelic football, camogie and ladies football, from club level to inter-county.

A React Native app built with Expo, for iOS and Android.

## Run it

```bash
npm install
npx expo start
```

Scan the QR code with [Expo Go](https://expo.dev/go) on your phone, or press `w` for a web preview.
